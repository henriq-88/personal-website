For my Master's degree I decided to put everything I learned into practice. With my computer science background I wanted to develop something. And with the things I learned during my master's I wanted to develop with the user in focus. Therefore I created an adaptive Android keyboard that tries to predict what letter the user will press next by changing the sizes of the buttons. Keys that are less likely to be pressed collapses and keys that are more likely to be pressed expands.

The prediciton engine uses Facebook chat messages and posts as learning data. This ensures that the user's own language is captured and predicted, instead of a generic dictionary's words.
